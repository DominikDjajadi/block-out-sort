# Contributing

This repository is publicly viewable for portfolio review and technical discussion, but it is not currently accepting external code contributions.

Bug reports and focused technical feedback are welcome through GitHub Issues. Please do not submit pull requests or code patches unless the maintainer has requested them in advance.

Changes to game rules must remain aligned between the JavaScript and Python engines and should include a shared conformance fixture. Changes to datasets, training, or evaluation must preserve explicit schema versions and deterministic experiment identities.

Do not submit model checkpoints, replay buffers, generated run directories, sealed evaluation pools, machine-specific configuration, credentials, or personal data.
